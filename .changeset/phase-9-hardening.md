Post-cutover hardening of the TanStack + Effect + D1 web lane.

- **Row models are `Model.Class`.** Every `@gmacko/db` table has one declaration in `packages/domain/src/models`, deriving the database (`select`/`insert`/`update`) and JSON (`json`/`jsonCreate`/`jsonUpdate`) variants from one field list. The contract classes are `Schema.Class`es over the `json` fields, so the OpenAPI document is unchanged while an API key hash, a key's owner id and the Stripe customer/subscription ids are `Model.Sensitive` and structurally cannot reach the wire. A parity suite in `@gmacko/db` fails if a Drizzle column and a model field drift apart in either direction.
- **Real rate limiting.** Cloudflare Rate Limiting bindings (`ratelimits` in `wrangler.jsonc`) for the `auth`, `contact`, `api-keys` and `operator-api` scopes, and a global counter in a new `rate_limit_window` D1 table for `signup` — sign-up and magic-link send create an account or send mail, where a per-colo count is not enough. better-auth's own `/api/auth/*` routes are gated too; they never reach the contract's middleware. Both counters fail open. A Cron Trigger runs the new `Jobs` service, which prunes closed windows.
- **Previews keep one shared D1**, with a `reset` job in `.github/workflows/preview.yml` (weekly and on demand) that migrates, empties and re-seeds it. The per-PR database the plan called for would need a Worker per PR, and a fresh Worker has no secrets. `pnpm -F @gmacko/db seed:remote` and `reset:remote` are the manual equivalents; `seed/reset.sql` is generated from the schema, children before parents.
- **Storage is Cloudflare R2.** `@gmacko/storage` writes to an R2 bucket through the Worker's binding. The bucket is a parameter rather than a module global, so the fault lane passes a CloudFault-proxied binding and injects real R2 failures into the same code path production runs. Uploads are authorized, content-type checked, and size-capped against the bytes actually received rather than a `Content-Length` the client chose; `putLarge` switches to multipart past the single-request ceiling. `packages/storage/README.md` sets out what a managed uploader used to do that is now the app's job, starting with virus scanning, which R2 does not provide.
- **Postgres → D1 migration recipe** for apps moving off the old template: `scripts/pg-to-d1.mjs` converts a `pg_dump --column-inserts` file (or a live database) using the real D1 schema from the newest drizzle snapshot — uuid to text, timestamps to epoch milliseconds, booleans to 0/1, json to text, identifiers matched by snake_case, tables emitted parents-first. `docs/legacy/postgres-to-d1.md` is the procedure, including what it will not do.
- **Tooling.** `@effect/language-service` in the base tsconfig's `plugins` (editor-only Effect diagnostics), and `.oxlintrc.json` now mirrors the one app standard oxlint can express (`no-cloudflare-env-outside-runtime`), with the reason each of the other eight cannot.
