# OpenAPI spec changelog

## 2.0.0 — the Effect HttpApi contract (breaking)

The spec is now `OpenApi.fromApi(AppApi)` over `@gmacko/domain`, the same
document `packages/domain` pins in its snapshot test. Every generated SDK
(`tooling/openapi-generator`) is a new major: nothing from the tRPC-era spec
survives by name.

### Paths

The tRPC procedures under `/v1/trpc/<router>.<procedure>` are gone. Endpoints
are REST resources under `/api` (health probes keep their absolute paths):

| Before                                   | After                                             |
| ---------------------------------------- | ------------------------------------------------- |
| `POST /v1/trpc/auth.getSession`          | `GET /api/auth/session`                           |
| `GET /v1/trpc/post.all`                  | `GET /api/posts`                                  |
| `GET /v1/trpc/post.byId`                 | `GET /api/posts/{id}` (404 `NotFound`)            |
| `POST /v1/trpc/post.create`              | `POST /api/posts` (201, returns the post)         |
| `POST /v1/trpc/post.delete`              | `DELETE /api/posts/{id}` (204)                    |
| `settings.getLaunchState`                | `GET /api/launch-state`                           |
| `settings.submitWaitlistEntry`           | `POST /api/waitlist` (201)                        |
| `settings.getWorkspaceContext`           | `GET /api/workspace`                              |
| `settings.listInvites` / `createInvite`  | `GET` / `POST /api/workspace/invites`             |
| `settings.acceptInvite`                  | `POST /api/workspace/invites/{inviteId}/accept`   |
| `settings.getPreferences` / `update...`  | `GET` / `PATCH /api/preferences`                  |
| `settings.listApiKeys` / `createApiKey`  | `GET` / `POST /api/api-keys`                      |
| `settings.revokeApiKey`                  | `DELETE /api/api-keys/{id}`                       |
| `settings.deleteAccount`                 | `DELETE /api/account`                             |
| `admin.*`                                | `/api/admin/*`; bootstrap at `/api/bootstrap`     |

### Components

Schemas are named after the contract's classes (`Post`, `CreatePost`,
`UserPreferences`, `ApiKeyCreated`, `WorkspaceContext`, ...); the encoded
(wire) variants carry the `Encoded` suffix. Errors are tagged objects with
one component per tag: `Unauthorized` (401), `Forbidden` (403, `reason`),
`NotFound` (404, `resource`, `id`), `Conflict` (409, `reason`), `RateLimited`
(429, `retryAfterSeconds`), `InternalError` (500), and the health probes'
503 shapes. A request the server's decoder refuses is an empty 400.

### Security

Two schemes: `session` (the `better-auth.session_token` cookie) and `apiKey`
(`Authorization: Bearer gmk_...`). Each operation lists the schemes it
accepts; docs/API_AUTH.md carries the credential and scope matrix.

### Versioning

`API_VERSION_TARGET` and the per-version documents are gone: there is one
contract, versioned by `@gmacko/domain`'s package version in `info.version`.

### Generated TypeScript package

The generated TypeScript SDK's npm name is now `@gmacko/openapi-client`;
`@gmacko/api-client` is the workspace's typed Effect client.

## 1.x

tRPC-era spec generated by `@gmacko/legacy-api/openapi` (versioned paths under
`/v1/trpc`).
